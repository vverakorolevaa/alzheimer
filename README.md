# Дифференциальная экспрессия генов при болезни Альцгеймера

Курсовой проект по биоинформатике. Анализ одноклеточного РНК-секвенирования (scRNA-seq) энторинальной коры: поиск дифференциально экспрессированных генов (DEG) и отбор **минимальной панели генов-биомаркеров** для ранней диагностики.

## Проблема и цель

Болезнь Альцгеймера поражает **55+ млн человек** (ВОЗ, 2023). Патология начинается за **10–20 лет** до симптомов, а к моменту клинического диагноза уже необратимо утрачено **30–40% нейронов гиппокампа** (Jack et al., 2018). Одобренные препараты (Lecanemab, Donanemab) работают только на ранней стадии — поэтому критична **ранняя молекулярная диагностика**.

**Цель:** по транскриптому клеток мозга (1) найти, какие гены и типы клеток затронуты болезнью, и (2) отобрать минимальный набор генов, по которому можно отличить больного от здорового — основу для дешёвого клинического теста.

## Данные

**GSE138852** (Grubman et al., *Nature Neuroscience*, 2019) — открытый датасет с NCBI GEO, **без ограничений доступа**:

- **13 214 клеток** энторинальной коры (область, первой поражаемой при AD)
- **6 батчей по 2 донора**: 3 батча с AD + 3 контроля
- **8 типов клеток**: нейроны, астроциты, микроглия, олигодендроциты, OPC, эндотелий и др.
- Матрица экспрессии: ~10 850 генов × клетки

Скачивается одной командой: `python cli.py download`.

## Пайплайн

```
GSE138852 (scRNA-seq)
   │
   ├─ Предобработка (scanpy): фильтрация клеток/генов, нормализация, log1p
   │
   ├─ DEG-анализ по каждому типу клеток отдельно
   │     Mann-Whitney U  →  FDR Бенджамини-Хохберга  →  |log2FC| > 1
   │
   ├─ Pathway enrichment (Enrichr API): GO / KEGG нарушенные пути
   │
   └─ Мини-панель биомаркеров  ◀── НОВИЗНА
         отбор PANEL_SIZE генов + честная донор-уровневая валидация
```

## Новизна — мини-панель генов-биомаркеров

Полный транскриптом измеряется только дорогим scRNA-seq. Но если найти **маленький** набор генов, его реально поставить на дешёвую клиническую платформу (qPCR, NanoString) — это путь к доступной ранней диагностике.

Из ~10 850 генов отбирается панель из **12 генов** (`config.PANEL_SIZE`):

| Результат | AUC (честный, донор-уровень) | Число генов |
|---|---|---|
| Мини-панель | **0.79 ± 0.12** | **12** |
| Полная модель | 0.96 ± 0.04 | 2000 |

Панель из 12 генов сохраняет большую часть диагностического сигнала, используя в **160 раз меньше** генов. График зависимости качества от размера панели — `results/biomarker_panel.png`.

**Состав панели (пример запуска):** LINGO1, NRXN1, NEAT1, RORA, SPP1, HSPA1A (известные AD-гены) + LSAMP, CTNNA2, GPM6A, NKAIN3 и др. (синаптические/нейрональные кандидаты). **6 из 12** генов независимо подтверждены литературой по AD — это биологическая валидация метода.

## Честность валидации — ключевой принцип

Данные содержат всего 6 батчей-доноров, и клетки одного пациента очень похожи. **Наивный подход** — разбивать train/test по отдельным клеткам — приводит к утечке: модель выучивает «личность» донора, а не биологию болезни, и AUC искусственно завышается до ~0.96+.

Поэтому панель валидируется **на уровне донора**: на каждом из 3 фолдов целый батч AD + батч контроля уходят в тест и моделью **не виданы**. Это честная оценка того, как панель сработает на **новом пациенте** — ровно сценарий ранней диагностики. Отбор генов производится только на обучающей части каждого фолда (без подглядывания в тест).

## Запуск

```bash
python3 -m venv venv && source venv/bin/activate
pip install -r requirements_full.txt

python cli.py download    # скачать GSE138852 с NCBI GEO (~270 МБ counts + covariates)
python cli.py analyze     # DEG по типам клеток + классификатор + Enrichr
python cli.py panel       # отбор мини-панели генов-биомаркеров (новизна)
```

## Методики

**DEG-анализ** (`gene_analyzer.py`):
- Критерий Манна-Уитни (U-test) для каждого гена: AD vs контроль, отдельно по типам клеток
- Поправка на множественные сравнения: Бенджамини-Хохберг, FDR < 0.05
- Порог биологической значимости: |log2FC| > 1.0

**Отбор панели** (`biomarker_panel.py`):
- Предфильтр: топ-2000 вариабельных генов (без меток — без утечки)
- Ранжирование внутри фолда: ANOVA F-критерий на обучающей части
- Классификатор: логистическая регрессия с балансировкой классов
- Валидация: донор-уровневый CV (3 фолда), AUC ± std
